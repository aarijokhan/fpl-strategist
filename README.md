Agentic Fantasy Premier League transfer strategist powered by LangGraph. Given a team ID, the agent fetches live FPL data, proposes a transfer, validates it against league constraints, self-corrects through a visible replan loop if needed, selects a captain, and explains its reasoning in natural language.
